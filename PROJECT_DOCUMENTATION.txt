 1. Project Overview

 1.1 Introduction

BOOKMYCOOK is a full-stack web application designed to connect customers with professional chefs, caterers, and decoration service providers in Tamil Nadu, India. The platform enables users to discover, book, and pay for event services through a seamless digital experience.

 1.2 Technology Stack

| Layer | Technology | Version |
|-------|------------|---------|
| Frontend Framework | React.js | 19.x |
| Frontend Build Tool | Vite | 8.x |
| CSS Framework | Tailwind CSS | 4.x |
| Backend Framework | Python Flask | 3.0+ |
| ORM | SQLAlchemy | 3.1+ |
| Database | PostgreSQL | 15+ |
| Authentication | JWT (Flask-JWT-Extended) | 4.6+ |
| Payment Gateway | Razorpay | Mock Implementation |
| Icon Library | Heroicons | 2.x |

 1.3 User Roles

| Role | Description |
|------|-------------|
| Customer | Browses services, makes bookings, writes reviews |
| Chef | Professional chef offering cooking services |
| Caterer | Catering company for events |
| Decorator | Event decoration specialist |
| Admin | Platform administrator with full access |

 1.4 Key Features

- User registration and authentication
- Service listing and discovery
- Real-time availability management
- Booking request and confirmation workflow
- Secure payment processing (Razorpay)
- Review and rating system
- Messaging system
- AI-powered chatbot (Cheffy)
- Admin dashboard
- Two-factor authentication
- Enterprise-grade security

 4.2 Users Table

sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    full_name VARCHAR(255) NOT NULL,
    phone VARCHAR(15),
    role VARCHAR(20) DEFAULT 'customer',
    is_verified BOOLEAN DEFAULT FALSE,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);


| Column | Type | Constraints | Description |
|--------|------|--------------|-------------|
| id | SERIAL | PRIMARY KEY | Auto-incrementing ID |
| email | VARCHAR(255) | UNIQUE, NOT NULL | User email address |
| password_hash | VARCHAR(255) | NOT NULL | Bcrypt hashed password |
| full_name | VARCHAR(255) | NOT NULL | User's full name |
| phone | VARCHAR(15) | | Phone number |
| role | VARCHAR(20) | DEFAULT 'customer' | User role (customer/chef/caterer/decorator/admin) |
| is_verified | BOOLEAN | DEFAULT FALSE | Email verification status |
| is_active | BOOLEAN | DEFAULT TRUE | Account active status |
| created_at | TIMESTAMP | DEFAULT NOW | Account creation timestamp |
| updated_at | TIMESTAMP | DEFAULT NOW | Last update timestamp |

 4.3 Profiles Table

sql
CREATE TABLE profiles (

 4.4 Services Table

sql
CREATE TABLE services (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    title VARCHAR(255) NOT NULL,
    description TEXT,
    service_type VARCHAR(20) NOT NULL,
    experience_years INTEGER DEFAULT 0,
    price_per_event DECIMAL(10,2),
    price_unit VARCHAR(20) DEFAULT 'per_event',
    cuisine_types JSONB,
    event_types JSONB,
    serves_veg BOOLEAN DEFAULT TRUE,
    serves_non_veg BOOLEAN DEFAULT FALSE,
    min_guests INTEGER DEFAULT 10,
    max_guests INTEGER DEFAULT 500,
    city_id INTEGER REFERENCES cities(id),
    area_id INTEGER REFERENCES areas(id),
    images JSONB,
    rating DECIMAL(3,2) DEFAULT 0,
    total_reviews INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    is_verified BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);


| Column | Type | Description |
|--------|------|-------------|
| service_type | VARCHAR(20) | chef, caterer, or decorator |
| cuisine_types | JSONB | Array of cuisine types served |
| event_types | JSONB | Array of event types handled |
| images | JSONB | Array of image URLs |
| rating | DECIMAL(3,2) | Average rating (0.00 - 5.00) |
| total_reviews | INTEGER | Count of reviews |

 4.5 Bookings Table

sql
CREATE TABLE bookings (
    id SERIAL PRIMARY KEY,
    service_id INTEGER REFERENCES services(id),

    event_type VARCHAR(100),
    event_address TEXT,

    special_requirements TEXT,
    base_amount DECIMAL(10,2),
    extra_charges DECIMAL(10,2) DEFAULT 0,
    total_amount DECIMAL(10,2),
    status VARCHAR(20) DEFAULT 'pending',
    rejection_reason TEXT,
    cancelled_by INTEGER REFERENCES users(id),
    cancellation_reason TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

);

    max_guests = db.Column(db.Integer, default=500)

@auth_bp.route('/register', methods=['POST'])
@limiter.limit('3 per hour')
def register():
    data = request.get_json()
    
     Validate input
    is_valid, result = validate_request(UserRegistrationSchema, data)
    if not is_valid:
        return jsonify({'message': 'Validation error', 'errors': result}), 400
    
     Validate password strength
    is_strong, errors = validate_password(data['password'])
    if not is_strong:
        return jsonify({'message': 'Password too weak', 'errors': errors}), 400
    
     Check existing user
    if User.query.filter_by(email=data['email']).first():
        return jsonify({'message': 'Email already registered'}), 400

    user = User(
        email=data['email'],
        full_name=data['full_name'],
        phone=data.get('phone'),
        role=data.get('role', 'customer')
    )
    user.set_password(data['password'])
    
    db.session.add(user)
    db.session.commit()
    
     Generate token
    token = create_access_token(identity=str(user.id))
    
     Log event
    log_auth_event(AuditEventType.REGISTER, user_id=user.id, email=data['email'])
    
    return jsonify({
        'message': 'User registered successfully',
        'token': token,
        'user': user.to_dict()
    }), 201

@auth_bp.route('/login', methods=['POST'])
@limiter.limit('5 per minute')
def login():
    data = request.get_json()
    
     Check account lockout
    is_locked, locked_until, remaining = is_account_locked(data['email'])
    if is_locked:
        return jsonify({
            'message': 'Account locked',
            'locked': True,
            'remaining_minutes': remaining
        }), 423
    
     Find user
    user = User.query.filter_by(email=data['email']).first()
    
    if not user or not user.check_password(data['password']):
         Record failed attempt
        is_now_locked, remaining = record_failed_attempt(data['email'])
        return jsonify({
            'message': 'Invalid credentials',
            'remaining_attempts': remaining
        }), 401
    
     Clear failed attempts
    clear_failed_attempts(data['email'])
    
     Generate token
    token = create_access_token(identity=str(user.id))
    
     Log event
    log_auth_event(AuditEventType.LOGIN_SUCCESS, user_id=user.id, email=data['email'])
    
    return jsonify({
        'message': 'Login successful',
        'token': token,
        'user': user.to_dict()
    }), 200

 8.3 Account Lockout

python
 app/utils/account_lockout.py
MAX_LOGIN_ATTEMPTS = 5
LOCKOUT_DURATION_MINUTES = 15

class FailedLoginAttempt(db.Model):
    __tablename__ = 'failed_login_attempts'
    
    id = db.Column(db.Integer, primary_key=True)
    email = db.Column(db.String(255), nullable=False, index=True)
    ip_address = db.Column(db.String(45))
    attempt_count = db.Column(db.Integer, default=1)
    last_attempt = db.Column(db.DateTime, default=datetime.utcnow)
    locked_until = db.Column(db.DateTime, nullable=True)

def is_account_locked(email):
    record = FailedLoginAttempt.query.filter_by(email=email.lower()).first()
    if not record:
        return False, None, MAX_LOGIN_ATTEMPTS
    if record.locked_until and record.locked_until > datetime.utcnow():
        return True, record.locked_until, 0
    return False, None, MAX_LOGIN_ATTEMPTS - record.attempt_count

def record_failed_attempt(email):
    record = FailedLoginAttempt.query.filter_by(email=email.lower()).first()
    if record:
        record.attempt_count += 1
        if record.attempt_count >= MAX_LOGIN_ATTEMPTS:
            record.locked_until = datetime.utcnow() + timedelta(minutes=LOCKOUT_DURATION_MINUTES)
            db.session.commit()
            return True, 0
    else:
        record = FailedLoginAttempt(email=email.lower(), attempt_count=1)
        db.session.add(record)
    db.session.commit()
    return False, MAX_LOGIN_ATTEMPTS - record.attempt_count

 8.5 Password Policy

python
 app/utils/password_policy.py
import re

COMMON_PASSWORDS = {
    'password', 'password123', '123456', '12345678', 'qwerty',
    'abc123', 'monkey', 'letmein', 'dragon', 'master', 'admin',
    'bookmycook', 'chennai', 'tamilnadu', 'india',
}

class PasswordPolicy:
    def __init__(self):
        self.min_length = 8
        self.require_uppercase = True
        self.require_lowercase = True
        self.require_numbers = True
        self.require_special = True
    
    def validate(self, password):
        errors = []
        
        if len(password) < self.min_length:
            errors.append(f'Password must be at least {self.min_length} characters')
        
        if self.require_uppercase and not re.search(r'[A-Z]', password):
            errors.append('Password must contain uppercase letter')
        
        if self.require_lowercase and not re.search(r'[a-z]', password):
            errors.append('Password must contain lowercase letter')
        
        if self.require_numbers and not re.search(r'\d', password):
            errors.append('Password must contain a number')
        
        if self.require_special and not re.search(r'[!@$%^&(),.?":{}|<>]', password):
            errors.append('Password must contain special character')
        
        if password.lower() in COMMON_PASSWORDS:
            errors.append('Password is too common')
        
        return len(errors) == 0, errors

    return pyotp.random_base32()

def verify_code(secret, code, valid_window=1):
    totp = pyotp.TOTP(secret)
    return totp.verify(code, valid_window=valid_window)

def generate_qr_code(email, secret):
    totp = pyotp.TOTP(secret)
    uri = totp.provisioning_uri(name=email, issuer_name='BOOKMYCOOK')
    
    qr = qrcode.QRCode(version=1, box_size=10, border=4)
    qr.add_data(uri)
    qr.make(fit=True)
    
    img = qr.make_image()
    buffer = io.BytesIO()
    img.save(buffer, format='PNG')
    
    return f"data:image/png;base64,{base64.b64encode(buffer.getvalue()).decode()}"

 13. Troubleshooting

 13.1 Common Issues

 Database Connection Error


Error: Could not connect to database


Solution: Check DATABASE_URL in .env and ensure PostgreSQL is running.

 JWT Token Invalid

Solution: Clear sessionStorage and login again. Check JWT_SECRET_KEY.

 CORS Error

Solution: Ensure Flask-CORS is configured correctly and frontend is using correct API URL.
